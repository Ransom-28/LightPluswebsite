# LightPlus Cleaning Services Website

## Overview

This is a fully responsive website for LightPlus Cleaning Services. The site features a clean, modern design with a blue theme matching the company logo. The website includes the following sections:

- Header with logo and navigation menu
- Hero section with a tagline
- Services section showing three types of cleaning services
- About section describing the company mission and values
- Contact section with a form to send messages
- Responsive layout for desktop and mobile devices

## Setup and Usage

1. Download or clone the project files.
2. Open `index.html` in any modern web browser.
3. The site is fully functional and responsive without additional setup.
4. To customize content or styles, edit `index.html` and `styles.css`.

## Files

- `index.html` - Main HTML structure with semantic elements
- `styles.css` - Styling and responsive layout
- `img/logo.png` - Company logo used in the header
- `README.md` - This documentation file

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
